# Cardápio — Sistema para Confeitaria

Sistema web para gerir e vender os produtos de uma confeitaria:

- **Área do dono (painel):** Dashboard, Pedidos, Cardápio, Estoque, Ficha técnica e precificação, Configurações.
- **Área do cliente (loja online):** vitrine mobile first no estilo iFood, sacola, checkout, pedido pelo WhatsApp e acompanhamento.

Em construção.
